# Security Policy

## Scope

This repository contains documentation, scripts, and configuration examples
related to KVM/QEMU GPU passthrough on Linux Mint.

## Sensitive Information

This repository intentionally excludes:

- passwords
- authentication tokens
- private keys
- recovery codes
- USB TFA serial numbers
- Windows product keys
- virtual machine disk images
- installation ISOs
- browser profiles
- credential stores

Host-specific identifiers and paths may be sanitized where they are not
necessary to demonstrate the configuration.

## Reporting Security Issues

If you discover sensitive information that was accidentally committed,
please contact the repository owner privately rather than opening a public issue.
